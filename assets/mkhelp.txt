Available targets:
 audit  - Run uv audit, (if present) zizmor (with online audits, getting token using gh auth token), and (if present) betterleaks sequentially
 badges - Run the test suite twice, exiting on any failure; generate static badges on success
 bug    - File a bug report in the browser with prefilled environment information
 build  - Build the Docker image for the asyncutils CLI locally
 clean  - Clean development artifacts and caches, including __pycache__/, build/, dist/, generated files, and coverage results
 dclean - Equivalent to git clean -dxf
 docs   - Build the documentation in HTML format in docs/build/html, exiting with a non-zero status on any warning; requires internet access
 help   - Show this help message; the default target
 links  - Check that links in the documents are valid using the Sphinx linkcheck builder
 lint   - Run ruff and ty sequentially, followed by CSpell, markdownlint-cli2 and sphinx-lint if found
 lock   - Update dependencies and regenerate uv.lock
 log    - Print Git history with colour using less in the terminal
 pc     - Run prek hooks on all files, unlike the run before each commit which only runs on modified files
 rel    - Make a release interactively using the GitHub CLI
 run    - Run the Docker image
 setup  - Create a virtual environment, install the package in editable mode with development dependencies inside and install prek hooks
 test   - Run tests, allowing up to AUTESTMAXFAIL failures (default 3) since any more would likely mean an obvious error
Targets may be added on popular demand.
